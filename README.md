项目简介
本项目基于 Kaggle 真实泰坦尼克号乘客数据集（train.csv），完成数据校验、特征预处理、模型训练与性能评估全流程。项目搭建了基线模型（DummyClassifier）与候选模型（随机森林），通过多维度分类指标对比模型性能，同时记录模型错分样本，完成模型效果复盘与问题分析，是典型的二分类机器学习入门项目。
核心任务：根据乘客舱位、性别、年龄、票价、登船港口等特征，预测乘客是否在海难中存活。
项目文件结构
├── data/
│   └── raw/
│       └── train.csv      # 原始泰坦尼克数据集（891条真实乘客数据）
├── 主程序.py               # 核心代码：数据校验、预处理、模型训练、评估
├── metrics.json            # 自动生成：数据集信息、基线/候选模型完整评估指标
└── errors.csv              # 自动生成：模型预测错误的测试集样本，用于错误分析
环境依赖
项目基于 Python 机器学习生态，所需依赖库：
- pandas：数据读取、数据处理与样本筛选
- scikit-learn：数据划分、预处理、模型搭建、指标评估
- json：评估结果文件持久化存储
安装依赖命令：
pip install pandas scikit-learn
核心功能说明
1. 数据校验模块
自动校验数据集完整性：检查文件是否存在、列名是否齐全、样本总量是否为891条、存活/死亡样本分布是否符合官方原版数据，杜绝无效数据影响模型训练。同时统计年龄、船舱、登船港口的缺失值数量。
2. 数据预处理流水线
针对数值型、分类型特征差异化处理，适配机器学习模型输入要求：
- 数值特征（Pclass、Age、SibSp、Parch、Fare）：采用中位数填充缺失值，规避异常值影响
- 分类特征（Sex、Embarked）：众数填充缺失值 + 独热编码（OneHot），将文本特征转为可计算数值
3. 双模型搭建
- 基线模型（DummyClassifier）：固定预测训练集多数类别（全员预测死亡），作为模型性能最低基准，用于验证有效模型的提升效果
- 候选模型（RandomForestClassifier）：随机森林分类模型，学习特征与乘客存活的关联规律，性能显著优于基线模型
4. 多维度模型评估
摒弃单一准确率指标，从业务角度综合评估模型，输出核心指标：整体准确率、存活精确率、存活召回率、F1分数、混淆矩阵，全面反映模型优劣。
运行指令

python 主程序.py --check-data
2. 完整运行项目（数据处理、模型训练、评估、生成结果文件）
python 主程序.py
输出结果说明
1. metrics.json
存储完整项目运行结果，包含：数据集基本信息、特征缺失值统计、基线模型指标、随机森林候选模型指标，可直接用于作业复盘与结果展示。
2. errors.csv
汇总所有测试集错分样本，记录乘客ID、原始特征、真实存活标签、模型预测标签，用于针对性分析模型缺陷。
项目核心知识点复盘
1. 样本全流程追踪
任意一条真实乘客数据从 train.csv 读取后，依次经过数据校验、特征筛选、数据集划分、缺失值填充、特征编码、模型推理，最终输出预测结果；错误样本会自动归档至 errors.csv，全程可追溯。
2. 基线模型的意义
DummyClassifier(strategy="most_frequent") 是极简基线模型，不学习任何数据规律，仅统计样本多数类别进行预测。逻辑简单、结果可复现，是衡量机器学习模型是否有效的最低性能标尺，可直观暴露数据集不平衡导致的准确率误导问题。
3. 评估指标的业务价值
以 存活召回率（recall_survived） 为例：计算公式为「真实存活且预测存活人数 / 全部真实存活人数」。适用于历史数据分析、救援复盘场景，核心价值是避免漏掉真实幸存者；不同业务场景对精确率、召回率、准确率的优先级不同，指标选择由使用者的业务代价决定，无通用最优指标。
4. 错误分析与迭代思路
模型存在错分样本（FN/FP错误），说明模型无法完全拟合所有数据规律。后续可通过分析 errors.csv，统计错误样本是否集中在特定舱位、性别、缺失值场景，针对性优化特征工程、调整模型超参数。
5. 实验验证原则
AI 辅助给出的模型、参数优化建议均为假设，需手动验证：核对代码实现、运行程序、比对 metrics.json 和 errors.csv 输出结果，确保结论真实有效，而非直接采信智能体建议。
